# Projek-1-Adit

Kumpulan proyek aplikasi Android Studio:

1. **AplikasiPertama** - Latihan dasar pembuatan aplikasi Android.
2. **IntentActivity** - Implementasi Intent untuk navigasi antar Activity di Android.
3. **MenghitungNilaiMahasiswa** - Aplikasi perhitungan nilai dan evaluasi mahasiswa.
4. **MengirimDataAntarActivity** - Implementasi pengiriman data antar Activity menggunakan Intent.
